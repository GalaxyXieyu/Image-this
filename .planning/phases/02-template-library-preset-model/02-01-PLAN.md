# Phase 2 Plan: Template Library and Preset Model

## Goal

建立模板库作为新版工作流入口，支持分类、预览、详情和一键使用。实现必须严格匹配 Pencil 设计稿 `/Users/galaxyxieyu/Documents/image-this.pen` 中"模板库"页面的视觉和交互。

## Scope

- 模板库页面 `/templates` 完整实现（三栏布局）
- 预设数据模型和类型定义
- 系统预设 seed 数据
- 从模板详情进入工作流的入口
- 不实现 DB 持久化（静态数据 + localStorage 可选缓存）

## Tasks

### Task 1: Define TemplatePreset Data Model

1. Extend `src/types/workbench/index.ts` with `TemplatePreset` type.
2. Fields:
   - `id`, `name`, `description`, `category` (enum: all, listing, whitebg, scene, poster, video, image-process)
   - `type`: 'scene' | 'tool' | 'combo'
   - `toolType?: 'background' | 'watermark' | 'upscale' | 'outpaint' | 'video'`
   - `thumbnailUrl?: string`
   - `usageCount: number`
   - `version: string`
   - `params`: Partial `SceneWorkflowDraft` | `ToolRunDraft` — the preset parameters
   - `tags: string[]`
   - `isSystem: boolean`
   - `createdAt`, `updatedAt`
3. Add `PresetCategory` enum.
4. Add `ComboPreset` type for组合模板.

### Task 2: Create System Preset Seed Data

1. Create `src/lib/workbench/presets.ts`.
2. Seed categories:
   - 上架图: 5 presets (主图全套、详情页首图、SKU图、卖点图、对比图)
   - 白底图: 3 presets
   - 场景图: 4 presets (室内家居、户外自然、商业办公、节日氛围)
   - 海报设计: 3 presets
   - 短视频: 2 presets
   - 图片处理: 3 presets (换背景、加水印、高清化)
3. Seed combos:
   - 淘宝全套素材: 包含上架图+白底图+场景图
   - 抖音带货套装: 包含视频+海报
4. Each preset must have realistic params that map to existing provider capabilities.

### Task 3: Implement Template Library Page Layout

**MUST match Pencil design exactly.**

1. Update `/templates/page.tsx` to use `WorkbenchShell`.
2. Three-column layout:
   - Left sidebar (260px): category navigation
   - Center content: search toolbar + template grid
   - Right detail panel (320px): preview + metadata + actions
3. Sidebar structure:
   - Section: "模板分类" with category list items
   - Divider (1px `$--border`)
   - Section: "组合模板"
   - Section: "功能导航" (links to tool pages)
4. Category items: height 40px, padding [10, 12], cornerRadius 8, gap 10.
   - Active: fill `$--primary`, text `$--primary-foreground`
   - Inactive: no fill, text `$--foreground`
5. Function nav items same style.

### Task 4: Implement Template Grid and Cards

1. Grid layout: responsive, gap 20px.
2. Card design (match Pencil exactly):
   - Height 280px, fill `$--card`, cornerRadius 12, stroke 1px `$--border`
   - Image area: 160px, `$--muted` fill, center icon (shopping_bag from Material Symbols) + "模板预览" label
   - Info area: padding 16px, vertical gap 4px
   - Title: Inter 15px weight 500, `$--foreground`
   - Description: Geist 13px, `$--muted-foreground`
   - Footer row: usage count (11px #999) + version badge (11px #0066FF)
   - Action row: "使用模板" (12px, #0066FF) + "编辑" (12px, #666)
3. Hover state: subtle shadow or border color change.
4. Click card → select and show in detail panel.

### Task 5: Implement Detail Panel

1. Panel width: 320px, fill `$--card`, left border 1px `$--border`.
2. Preview area: 180px height, `$--muted` fill, cornerRadius 12, icon + label.
3. Metadata section:
   - Template name (Inter 16px weight 600)
   - Description (Geist 14px)
   - Category badge
   - Usage count
   - Version
   - Tags
4. Parameters preview (collapsible): show key params from the preset.
5. Action buttons:
   - Primary: "使用此模板" → navigate to corresponding workflow/tool page with preset params
   - Secondary: "收藏" / "分享" (stubs)

### Task 6: Implement Search and Filter

1. Search input in toolbar: placeholder "搜索模板...", Geist 14px.
2. Filter: "最新发布" dropdown (sort by date/usage).
3. Real-time filtering of template grid.
4. Category click filters templates.

### Task 7: Wire Template to Workflow Entry

1. "使用此模板" button navigates based on preset type:
   - `type: 'scene'` → `/workspace/scene?preset={id}`
   - `type: 'tool'` → `/tools/{toolType}?preset={id}`
   - `type: 'combo'` → `/workbench?preset={id}` (combo flow)
2. Parse preset ID from URL query in target pages.
3. Initialize draft state from preset params.

### Task 8: Add Build Verification

1. Run `npm run build`.
2. Verify `/templates` route renders.
3. Verify navigation between categories, card selection, detail panel.
4. Verify "使用此模板" navigation works.

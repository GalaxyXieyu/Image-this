# ImageThis 品牌视觉速查

> 更新日期：2026-06-06  
> 品牌资产：`docs/brands/`

## 1. 品牌一句话

ImageThis / 想象此 是一个电商 AI 批量生图平台，帮助用户把商品图生成可销售的专业视觉资产。

| 项目 | 规范 |
|---|---|
| 品牌名 | ImageThis / Imagine This / 想象此 |
| 定位 | 电商 AI 批量生图应用平台 |
| 使命 | 让每个人都能创造专业级视觉内容 |
| 调性 | 趣味 × 未来感 × 高设计水准 |
| 关键词 | 创造力、年轻感、沉浸交互、实验精神 |

主口号：**让每件商品，都有一束属于自己的光。**

## 2. 视觉方向

推荐方向：**极境造物**。

| 要做 | 不要做 |
|---|---|
| 极光渐变、磨砂玻璃、空间纵深、微光折射 | 纯后台蓝白灰、廉价霓虹、过度卡通、游戏化 |
| 专业但不冷，漂亮但不浮夸 | 堆装饰、堆特效、牺牲工作台效率 |

## 3. Logo

| 项目 | 规范 |
|---|---|
| 主 Logo | 图标 + `ImageThis` 横版组合 |
| 变体 | 图标版 / 纯文字版 / 单色版 / 深浅底版本 |
| 安全区 | 四周至少预留 1 个图标宽度 |
| 最小尺寸 | 横版 ≥ 96px；图标 ≥ 24px |
| 禁忌 | 不拉伸、不旋转、不随意改色、不加复杂阴影 |

## 5. 字体与文字颜色

| 层级 | 字体建议 | 用途 |
|---|---|---|
| 大标题 | 现代无衬线黑体 / 几何无衬线体 | Hero、海报、品牌标语 |
| 副标题 | Medium 黑体 / 中等字重无衬线 | 区块标题、卡片标题 |
| 正文 | Regular 黑体 / 常规无衬线 | 说明文字 |
| 注释 | Light 黑体 / 细字重无衬线 | 标签、辅助信息 |

| 场景 | 大标题 | 正文 | 辅助 |
|---|---|---|---|
| 浅色背景 | `#2D3436` / `#000000` | `#2D3436` | `#636E72` |
| 深色背景 | `#FFFFFF` | `#B2BEC3` | `#DFE6E9` |
| 链接/强调 | `#0066FF` | `#6366F1` | `#FF3399` |

## 6. 图形与 IP

| 类型 | 规范 |
|---|---|
| 图形语言 | 几何图形、动态线条、粒子、渐变纹理、3D 悬浮感 |
| 品牌符号 | 多面体光核，优先用于 Logo、加载、空状态、生成按钮 |
| 吉祥物 | LUMO / 小光，蓝色科技小狗，头顶“光”字标志 |
| 使用边界 | LUMO 用于引导、加载、表情、周边；核心工作台保持专业克制 |

## 7. 应用规则

| 场景 | 重点 |
|---|---|
| 首页 | 第一眼品牌美感，允许使用极光渐变和品牌符号 |
| 场景工作台 | 生成按钮、进度、候选结果是重点 |
| 模板库 | 预览图优先，选中态使用极光微光 |
| 工具箱 | 像专业修图工具，减少表单感 |
| 任务中心 | 状态清楚、稳定，不做夸张庆祝 |
| 结果管理 | 图片优先，做成作品墙 |
| 设置 | 稳定可信，少用光效 |

# ImageThis 品牌与产品 UI 规范

> 更新日期：2026-06-06  
> 品牌资产目录：`docs/brands/`  
> 适用范围：首页、模板库、场景工作台、智能工具箱、任务中心、结果管理、设置页、Electron 桌面端

## 1. 当前结论

现有品牌图、色板截图和产品 UI token 之间没有形成同一套规则，需要收敛。

| 问题 | 处理原则 |
|---|---|
| 展示色板里同时出现电光蓝、霓虹粉、活力橙、薄荷绿、柠檬黄，容易变成儿童感或活动页感 | 产品 UI 只保留蓝作为主色；粉、橙只做少量业务强调 |
| 文档里品牌主色和产品 token 分裂，`#0066FF` 与 `#6366F1` 并存但没有层级 | `#2563FF` 作为主 CTA/链接/选中态；紫色只作为 AI 光效延展 |
| Logo 资产实际是深色单色为主，文档却暗示可随意进入彩色渐变体系 | Logo 保持深色/白色/单色优先，彩色只用于图标容器和品牌背景，不改 Logo 本体 |
| LUMO 小光偏可爱，和电商专业工作台存在冲突 | LUMO 只用于引导、空状态、加载、欢迎页；核心编辑区弱化使用 |
| 渐变、粒子、3D、星光都出现，但没有组合边界 | 只允许“蓝紫光感 + 大留白 + 克制点缀”，禁止多色堆叠 |

新版方向：**专业电商工作台 × 蓝紫 AI 光感 × 克制 IP 陪伴**。

## 2. 品牌定位

| 项目 | 规范 |
|---|---|
| 品牌名 | ImageThis |
| 英文展示 | ImageThis / Imagine This |
| 中文辅助 | 想象此 |
| 产品定位 | 电商 AI 商品视觉生产工作台 |
| 核心价值 | 把商品素材快速生成可上架、可批量管理的专业视觉资产 |
| 气质 | 专业、清晰、轻未来感、有创造力但不花哨 |
| 禁止气质 | 低龄卡通、廉价霓虹、游戏化后台、颜色过饱和、装饰压过效率 |

主口号：**让每件商品，都有一束属于自己的光。**

辅助口号：

- 上传商品，生成上架视觉。
- 从商品图到场景大片，一站完成。
- 为电商运营打造的 AI 视觉工作台。

## 3. Logo 规范

### 3.1 当前资产

| 路径 | 用途 | 使用建议 |
|---|---|---|
| `docs/brands/logo/imagethis-logo-horizontal.svg` | 横版 Logo | 顶部导航、登录页、落地页、文档页 |
| `docs/brands/logo/imagethis-logo-large.svg` | 大尺寸展示版 | 品牌展示页、封面图、演示物料 |
| `docs/brands/logo/imagethis-wordmark.svg` | 纯文字标识 | 空间紧张但仍需品牌名的区域 |
| `docs/brands/logo/imagethis-icon.svg` | 图标 | favicon、侧栏折叠、按钮小标识、加载状态 |
| `docs/brands/icon/ip1.svg` | LUMO / 小光 IP 1 | 欢迎、引导、空状态 |
| `docs/brands/icon/ip2.svg` | LUMO / 小光 IP 2 | 活动、提示、轻量说明 |

### 3.2 Logo 组合

| 场景 | 首选组合 | 说明 |
|---|---|---|
| 产品顶部导航 | 图标 + `ImageThis` 横版 | 不加中文副标题，保持干净 |
| 落地页 Hero | 横版 Logo + 主口号 | 可搭配蓝紫光感背景 |
| Electron 桌面窗口 | 图标版 | 与系统标题栏保持清晰 |
| 设置页/任务页 | 小图标 + 文字 | 不使用吉祥物抢焦点 |
| 社媒/封面 | 大尺寸 Logo + LUMO | 仅限品牌传播，不进入核心工作台 |

### 3.3 Logo 安全区与尺寸

| 项目 | 规范 |
|---|---|
| 安全区 | 四周至少预留 1 个图标内边距；在卡片或按钮里至少 12px |
| 横版最小宽度 | 96px |
| 图标最小尺寸 | 24px；低于 24px 时只用简化图标或 favicon |
| 导航推荐尺寸 | 图标 28–32px，横版宽度 120–148px |
| 登录/落地页推荐尺寸 | 横版宽度 160–220px |

### 3.4 Logo 禁忌

| 禁止项 | 原因 |
|---|---|
| 不拉伸、不压缩、不倾斜、不旋转 | 保持品牌识别稳定 |
| 不把 Logo 本体改成多色渐变 | 当前资产是深色单色逻辑，渐变应放在背景或容器 |
| 不给 Logo 加厚重投影、描边、霓虹边 | 会降低专业感 |
| 不把 LUMO 当 Logo 使用 | IP 是陪伴角色，不是品牌标识 |
| 不在复杂图片上直接放深色 Logo | 必须加浅色遮罩、白底容器或使用反白版 |

## 4. 色彩系统

### 4.1 色彩原则

产品 UI 使用一套主色体系：**蓝为主、紫为 AI 延展、粉橙只作少量强调**。

| 层级 | 颜色角色 | 使用比例 | 说明 |
|---|---|---:|---|
| 主色 | Blue | 65% | CTA、链接、选中、进度、导航高亮 |
| AI 延展 | Violet | 15% | 生成态、模板光效、AI 能力标识 |
| 强调 | Pink / Orange | 5% | 活动、重点提醒、转化提示，不能大面积铺开 |
| 功能色 | Success / Warning / Danger | 5% | 状态反馈 |
| 中性色 | Slate / White | 10% | 大面积背景、文字、边框 |

### 4.5 渐变规则

| 渐变 | 色值 | 用途 | 限制 |
|---|---|---|---|
| 主品牌渐变 | `#2563FF → #7C3AED` | Hero、主 CTA、生成按钮、选中光效 | 单屏最多 1 个主视觉区域 |
| 轻光渐变 | `#DBEAFE → #EDE9FE → #FFFFFF` | 页面背景、空状态、卡片柔光 | 透明度低，不能影响阅读 |
| 深色极光 | `#020617 → #1E1B4B → #2563FF` | 深色演示页、品牌封面 | 不进入普通表单页 |
| 暖色强调 | `#F43F8F → #F97316` | 活动按钮、促销 banner | 不能作为默认 CTA |

禁止组合：

- 蓝、粉、橙、绿、黄同时大面积出现。
- 每张卡片都使用不同渐变。
- 把主 CTA 做成粉橙渐变。
- 在工作台编辑区使用高饱和背景。

## 5. 字体与文字层级

| 场景 | 字体建议 | 说明 |
|---|---|---|
| 中文 | `Source Han Sans` / `Noto Sans SC` / 系统黑体 | 保证桌面端可读性 |
| 英文 | `Inter` / `Geist` / 系统无衬线 | 与当前 Next.js 设计体系一致 |
| 数字 | `Inter` / `Geist Mono` | 任务进度、价格、参数 |

| 层级 | 桌面字号 | 行高 | 字重 | 用途 |
|---|---:|---:|---:|---|
| Display | 48–64 | 1.05 | 700–800 | 首页 Hero、品牌封面 |
| H1 | 32–40 | 1.15 | 700 | 页面标题 |
| H2 | 24–28 | 1.2 | 650–700 | 区块标题 |
| H3 | 18–20 | 1.3 | 600 | 卡片标题、面板标题 |
| Body | 14–16 | 1.6 | 400–500 | 正文、说明 |
| Caption | 12–13 | 1.4 | 400–500 | 标签、辅助信息 |
| Data | 12–14 | 1.3 | 500–600 | 参数、任务状态、数值 |

文字规则：

- 工作台内不要使用过大的标题压缩操作空间。
- 页面标题清晰即可，不每页都做 Hero。
- 中文宣传语可以有温度，操作说明必须短、准、可执行。
- 按钮文案优先使用动词：`生成场景图`、`开始处理`、`保存到结果`。

## 6. 图形、光效与 IP

### 6.1 图形语言

| 元素 | 允许 | 禁止 |
|---|---|---|
| 几何图形 | 圆角矩形、柔和圆、轻量网格、光点 | 大量三角、星星、复杂装饰堆满界面 |
| 光效 | 蓝紫柔光、局部辉光、生成态进度光 | 全屏霓虹、强对比发光描边 |
| 3D | 商品盒、轻量悬浮卡片、结果墙 | 游戏道具感、过度卡通材质 |
| 粒子 | 少量背景点缀 | 干扰文字和图片判断 |

### 6.2 LUMO / 小光使用边界

| 场景 | 是否使用 | 规则 |
|---|---|---|
| 首页 Hero | 可以 | 作为品牌陪伴，不遮挡 CTA |
| 新手引导 | 推荐 | 解释流程、引导上传 |
| 空状态 | 推荐 | 缓解空白，但文案要直接 |
| 加载/生成中 | 可以 | 小尺寸动效或静态图，不要每个任务都出现 |
| 工作台画布 | 谨慎 | 不进入图片判断区域 |
| 设置页 | 不推荐 | 保持可信和安静 |
| 任务中心 | 不推荐 | 状态优先，不做庆祝式干扰 |

## 7. 页面级应用规则

| 页面 | 视觉重点 | 色彩策略 | Logo/IP 策略 |
|---|---|---|---|
| `/` 首页 | 建立专业 AI 商品视觉平台印象 | 可使用主品牌渐变和轻光背景 | 横版 Logo + 可用 LUMO |
| `/workspace/scene` 场景工作台 | 三步流程、商品信息、候选结果 | 白/浅灰底，蓝色选中，紫色仅标记 AI 生成 | 不使用大 IP |
| `/combo` 组合流程 | 多步骤、依赖关系、可视化链路 | 蓝色为流程主线，状态色清楚 | Logo 仅在导航 |
| `/tools` 智能工具箱 | 上传、参数、画布、结果 | 专业编辑器感，少渐变，多留白 | IP 不进入主画布 |
| `/tasks` 任务中心 | 状态、进度、失败重试 | 功能色优先，避免装饰色 | 不使用 IP |
| `/results` 结果管理 | 图片资产墙、筛选、批量动作 | 图片优先，UI 后退 | 不使用 IP |
| `/templates` 模板库 | 预览图、分类、详情 | 选中态可用蓝紫微光 | 可少量使用品牌图形 |
| `/settings` 设置 | 稳定、可信、凭据安全 | 中性色 + 蓝色链接 | 不使用 IP |

## 8. 品牌插图生成规范

产品插图可以使用现有 GPT 图片能力生成，但必须以正式 IP 资产为参考，不允许凭空重画成另一套角色。

### 8.1 参考资产

| 路径 | 用途 | 规则 |
|---|---|---|
| `docs/brands/icon/cut/ip2-trimmed-preview.png` | GPT 插图参考图 | 用作 LUMO 角色识别基准，保持蓝白角色、黑色贝雷帽、圆润 3D 卡通质感 |
| `docs/brands/icon/ip1.svg` | 静态 IP 资产 | 用于欢迎、空状态、引导 |
| `docs/brands/icon/ip2.svg` | 静态 IP 资产 | 用于提示、轻量说明、品牌展示 |

### 8.2 可生成场景

| 场景 | 是否允许 | 说明 |
|---|---|---|
| 首页 Hero 插图 | 允许 | 可生成 LUMO + AI 商品视觉生产场景 |
| 空状态插图 | 允许 | 用于模板为空、结果为空、任务为空等轻量引导 |
| 新手引导插图 | 允许 | 表达上传商品、选择模板、生成结果的流程 |
| 功能卡片插图 | 谨慎 | 只能做小尺寸辅助，不抢功能标题和 CTA |
| 工作台画布内插图 | 禁止 | 会干扰商品图判断 |
| 设置页插图 | 禁止 | 凭据和配置页面要保持可信、安静 |

### 8.3 GPT 插图提示词边界

基础提示词结构：

```text
基于参考图中的 Imagine This 品牌 IP 角色，生成一张用于{页面/状态}的品牌插图。
要求：保留蓝白小狗/兔耳机器人气质、黑色贝雷帽、友好表情、圆润 3D 卡通质感；
画面主题为{具体业务场景}；
包含轻量 UI 卡片、图片生成光效、蓝紫品牌科技氛围；
不要改变角色核心识别，不要出现真实摄影风格，不要出现杂乱背景，不要添加多余文字；
输出干净、现代、适合白底页面使用的 1024x1024 插图。
```

生成结果必须先作为候选稿进入人工筛选，不直接替换正式 Logo 或核心 UI 资产。

## 9. 组件组合规则

| 组件 | 默认 | 强调 | 禁止 |
|---|---|---|---|
| 主按钮 | 蓝底白字 | 蓝紫渐变仅用于生成类主按钮 | 同页多个渐变主按钮 |
| 次按钮 | 白底深字 + 浅边框 | hover 使用浅蓝底 | 灰度过低看不清 |
| 卡片 | 白底、浅边框、轻阴影 | 选中态蓝边 + 轻蓝底 | 多色边框、厚投影 |
| 标签 | 浅底深字 | AI 标签可用淡紫 | 高饱和实底堆满页面 |
| 进度条 | 蓝色 | 生成类可蓝紫过渡 | 彩虹进度条 |
| 状态徽标 | 成功绿、警告黄、失败红、处理中蓝 | 保持语义一致 | 用粉橙表达普通状态 |
| 输入框 | 白底、浅边框、蓝色 focus | 错误红边 | 霓虹 focus、厚阴影 |
| 结果卡 | 图片优先，操作后置 | hover 显示快捷操作 | 装饰盖过图片 |

## 10. 深浅色模式

| 项目 | 浅色模式 | 深色模式 |
|---|---|---|
| 默认背景 | `#F8FAFC` | `#020617` |
| 面板 | `#FFFFFF` | `#0F172A` |
| 文字 | `#0F172A` | `#F8FAFC` |
| 边框 | `#E2E8F0` | `#1F2937` |
| 主按钮 | `#2563FF` | `#60A5FA` |
| AI 强调 | `#7C3AED` | `#A78BFA` |

深色模式只在用户选择或特定演示页使用，不作为默认工作台主题。原因是商品图片判断、参数阅读和批量管理更适合浅色基线。

## 11. 落地检查清单

每次改 UI 前检查：

- 是否只使用一套主色 token。
- 主 CTA 是否仍是蓝色，不是粉橙。
- Logo 是否来自 `docs/brands/logo/`，且没有被改色、拉伸或加重阴影。
- LUMO 是否只出现在欢迎、引导、空状态等陪伴场景。
- 页面是否让图片、任务状态、操作路径优先于装饰。
- 同一屏是否只有一个最强视觉焦点。
- 状态色是否按语义使用，不和品牌强调色混用。
- 文案是否短、直接、可执行。
